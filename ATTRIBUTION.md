# AudioStrike source attribution

The complete workstation foundation derives from [SoundCraft](https://github.com/storytold/soundcraft) at `480b0b2dd75df388d79746a035652069a9bdcbc6`, by the ArtCraft Team and SoundCraft contributors. Its original dual-license files and `NOTICE` are included unchanged. The AudioStrike binary identity, preferences and control names, legacy converter, and save/export safety changes were added in the local adaptation. Package manifests declare MIT OR Apache-2.0 for the selected source.

No donor app icon, restricted ArtCraft brand files, promotional images, sample audio, or font files are included. Donor UI icons are generated by source code, and demo audio is synthesized by source code. [UPSTREAM_ATTRIBUTION.md](UPSTREAM_ATTRIBUTION.md) is the donor's historical inventory; its rows for omitted files are not a claim that those assets ship here. Upstream contributor metadata is omitted, so the About contributor table is empty.

The pinned `craft-ui` dependency is [storytold/craft-libs](https://github.com/storytold/craft-libs) revision `5c874d51eeb3de70e735c8ce87a59a7dedd47675`, MIT OR Apache-2.0. Its upstream `NOTICE` credits Craft editor source adaptations and must accompany a binary distribution with the relevant license texts. The added RustCrypto `sha2 0.10.9` is MIT OR Apache-2.0. A complete transitive binary redistribution inventory remains a release task.
