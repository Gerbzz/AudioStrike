The legacy converter adds RustCrypto `sha2 = =0.10.9`, MIT OR Apache-2.0; `Cargo.lock` includes that version and six supporting package records. The workspace states Rust 1.95 because the pinned UI dependency requires it. On a fresh Windows clone, fetch the pinned dependencies with `cargo fetch --locked --target x86_64-pc-windows-msvc`, then run the locked commands in [README.md](README.md).
